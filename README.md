# bio-dashboard
Dashboard for managing reagents, services, and projects for laboratories.
Created by Dr. Bradley J. Smith, of Quarium Consultoria em Biologia Analítica, Ltda., based in Campinas, SP, Brazil.
Software is a hybrid of Brazilian Portuguese and American English.
Written with assistance from AI tools, including Claude and Gemini.

IMPORTANT: When using this software, please place the binary in a working folder that it will have access to. Temporary database files, as well as your credentials.json and application logos will be saved in this folder.
